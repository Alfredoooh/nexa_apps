# Referência Flutter original

Esta pasta preserva o código Dart original e o `pubspec.yaml` para comparação e continuidade da migração. **Não faz parte do source set Android e não é incluída no APK.**

Os assets de referência estão em `source_assets/`. Os ícones Phosphor SVG originais foram convertidos para constantes Kotlin em `../android/app/src/main/kotlin/com/looply/browser/app/icons/phosphor/`; a cópia em `source_assets/icons/` serve apenas para auditoria e comparação. Os três logótipos de serviços de apostas foram excluídos das cópias distribuídas.
