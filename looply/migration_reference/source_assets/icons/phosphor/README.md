BrowseIt SVG icon set

Folders:
- regular/: outline weight
- fill/: denser filled/active weight

Each SVG is authored on a 24 × 24 viewBox and uses a single monochrome color that is tinted by PhosphorSvgIcon at runtime. The filenames are mapped to familiar Phosphor icon names. These application assets are original Phosphor-style redraws, not copied upstream Phosphor source files.
