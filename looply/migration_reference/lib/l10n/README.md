# BrowseIt localization catalogs

Each language has its own Dart catalog file: `pt.dart`, `en.dart`, `es.dart`, `fr.dart`, `de.dart`, `it.dart`, `ar.dart`, `zh.dart`, `ja.dart`, `ru.dart`, `hi.dart`, and `tr.dart`.

`translations.dart` combines the catalogs for the `appText()` lookup. The catalog is compiled as Dart source, so no extra pubspec asset declaration or generated localization package is required.
